# 📊 Customer Demography Study

## 📌 Project Overview

Customer Demography Study is a Data Analytics project developed using Python. The project focuses on analyzing customer demographic information and understanding customer characteristics, income distribution, spending behaviour, and purchasing preferences.

The project uses an interactive dashboard to present customer insights through charts, graphs, and statistical summaries.

## 🎯 Project Objectives

- Analyze customer age distribution.
- Understand gender distribution among customers.
- Study customer income across different professions.
- Identify popular product categories.
- Analyze the relationship between income and spending scores.
- Visualize customer demographic patterns using interactive charts.

## Technologies Used

- Python
- Pandas
- Streamlit
- Plotly
- CSV Dataset

## 📊 Dataset Description

The project uses a synthetic customer dataset containing 1,000 customer records.

The dataset includes the following attributes:

| Column | Description |:
| customer_id | Unique customer identification |
| age | Customer age |
| gender | Customer gender |
| annual_income | Annual customer income |
| spending_score | Customer spending score |
| education | Educational qualification |
| profession | Customer profession |
| marital_status | Marital status |
| family_size | Number of family members |
| city | Customer city |
| membership_years | Years of membership |
| purchase_frequency | Purchase frequency |
| preferred_category | Preferred product category |

**Note:** The dataset is synthetic and created for educational and demonstration purposes. It does not contain real customer personal information.

## 📈 Dashboard Features

### 1. Customer Overview
Displays:
- Total customers
- Average customer age
- Average annual income
- Average spending score

### 2. Age Distribution
Visualizes the distribution of customers across different age groups.

### 3. Gender Distribution
Displays the percentage and number of customers by gender.

### 4. Income Analysis
Compares annual income across different professions.

### 5. Product Category Analysis
Identifies customer preferences across different product categories.

### 6. Income vs Spending Score
Visualizes the relationship between annual income and customer spending scores.

### 7. Interactive Filters
Allows users to filter customer information by:
- City
- Gender
- Product category
- Age range

### 8. Data Download
Allows users to download filtered customer records in CSV format.
